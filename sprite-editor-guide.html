Sprite Editor — Chromebook Guide

Tesco Trueno · everything you need to build characters and never lose them

Four lines, then you can ignore the rest of this.

  1. export is the only save. Nothing is stored anywhere — close the tab and it is all gone.
  2. merge adds a file to what you have. import deletes what you have first. Press import once, at the start, and never again.
  3. Instant backup: press text, Ctrl+A, Ctrl+C, paste into a Google Doc. Four seconds.
  4. export again before you close the tab. Every time.

The Chromebook restarts itself for updates without asking. That is how people lose an afternoon.

Before you set out

Two files travel together:

  • sprite-editor.html — the workshop
  • cast.sprite.txt — the characters that already exist

Download both. They arrive in My Files > Downloads.

Open the Files app, make a folder in Google Drive called trueno, and drag both files into it.

Downloads is local storage. Nothing backs it up, and a powerwash empties it. Drive is safe ground. Work from Drive.

Entering the workshop

In the Files app, right-click sprite-editor.html and choose Open with > Chrome.

That is the whole install. It is one HTML file with no dependencies — nothing downloads, nothing phones home, and it works with the wifi off. The address bar will say file:/// rather than a website, which is correct.

Bookmark the tab once it is open. It is faster than going through Files every time.

It will be a black screen with an empty grid. That is right: the editor starts with nothing in it.

Loading the cast

Press import, pick cast.sprite.txt from your Drive folder, and eleven characters appear in the dropdown at the top left — Trueno, a seagull, a granny, a trolley, four cars and the rest.

Drag the background to spin the view, scroll to zoom, and press fit if something goes off screen.

Worth knowing what that file actually is: plain text you could open in any editor. One line per box, like this:

box 0.42 0 0.55  1.9 0.62 0.28  #d94f3a  n=bonnet top=#e8e8e8

Position, then size, then colour, then optional extras. There is a full explanation of the format written into the top of the file as comments.

This matters for one reason: if the editor ever breaks, your work is still readable text. Nothing is locked in a proprietary format.

Building a character

Everything is made of boxes. No curves, no meshes — you are working in the same vocabulary as a Lego minifig, and the charm is in what you can imply with eight or ten blocks.

The panels, left to right:

  • sprite — the character. new, dup, rename, del.
  • states — poses, as tabs. The granny has standing, walking, driving and pushing. dup a state and nudge things for the next frame.
  • boxes — the blocks in the current state.
  • properties — the selected box: position, size, rotation, colour.

Moving things

Click a box to select it. Hold and drag to move it, and it locks to one axis depending on which way you pull. Click a box that is already selected to pick a single face, then drag that face to resize in that direction. Click the background to drop everything and just look at it.

Arrow keys nudge the selected box by 1 cm. Hold Shift and they resize instead. D duplicates, Backspace deletes, Ctrl+Z undoes.

For up and down the keys are PageUp and PageDown, which a Chromebook does not have — Alt + ↑ and Alt + ↓ normally stand in. If that fights you, type the number into the z base field instead. The number fields always work.

Colour

Each box has a base colour, and each of its six faces can override it. Faces are named in the box's own frame (fwd, aft, lft, rgt, top, bot) so they stay correct when you rotate it. Alpha is a separate 0–100 box, and none makes a face invisible — which is how you make something hollow, like the inside of a trolley.

Three buttons that save you pain

  • no burying is on by default. It stops you hiding a box completely inside another one, where it costs memory and shows nothing.
  • ground to z=0 drops the whole sprite so its feet sit on the floor. Use it whenever something looks like it is hovering.
  • scale with apply resizes the entire character uniformly. Build at whatever size feels natural and fix it afterwards — or set a real-world height and press fit.

The mass field is in kilograms, for the physics later. Rough is fine. Per-box weight and balance are worked out from the shapes, so they survive scaling.

Import, merge, export

Three buttons, bottom left. Two of them are safe and one of them will eat your afternoon.

ButtonWhat it doesSafe?
importThrows away everything open and loads the file insteadNo. This is the dangerous one.
mergeAdds the file's characters alongside what you already haveYes
exportDownloads everything currently open as one text fileYes

The trap

import replaces. merge adds.

If you have spent two hours on a fox, then press import to bring in Dad's latest cast file, the fox is gone. No warning, no undo prompt. It is the one mistake in this tool that actually costs you work.

Use import once, at the start of a session, on an empty editor. After that, only ever use merge.

What merge does with clashing names

Nothing destructive. If you merge a file containing gull and you already have a gull, the incoming one becomes gull-2. Both survive and you rename whichever you prefer. Merge never overwrites a character.

Where exports land

export always names the file cast.sprite.txt, every time. Chrome will not overwrite, so your Downloads folder fills up with cast.sprite (1).txt, cast.sprite (2).txt and so on — and the highest number is your newest work, which is a horrible way to find anything.

Two things fix this:

  1. In Chrome, go to Settings > Downloads and change Location to your trueno folder in Google Drive. Now exports save straight to Drive instead of local storage.
  2. Rename each export as soon as it lands: fox-v3.txt, cat-sitting-pose.txt. Whatever means something to you.

The instant save

The text button shows everything currently open as plain text. Click in it, Ctrl+A, Ctrl+C, and paste into a Google Doc or Keep note.

No download, no file naming, about four seconds. If you are about to try something risky, do this first. Paste it back into the same panel and press apply to restore, or merge to bring it in alongside.

A routine that never loses anything

Four habits. They take about ten seconds each.

  1. Start: open the editor, import once.
  2. Every finished character, and before anything experimental: export, then rename the file.
  3. Every twenty minutes or so: text, select all, copy, paste into one running Google Doc. Do not delete the old pastes — that Doc becomes your version history for free.
  4. End: export before you close the tab. Always. Even if you think you changed nothing.

The Chromebook restarting itself for an update is the thing that catches people. It does not ask.

Sending work back

Export, rename to something like yourname-cast-v2.txt, and send that one file. Dad merges it into the main cast, so nothing of yours is overwritten and nothing of his is either.

You can send several files or one big one — merge handles both. New characters do not need to relate to anything already in there. A car park is a broad church.
